# Monocs リファレンスマニュアル

Raspberry Pi Zero 2 W で動く、C で書いたシンプルなベアメタル OS「Monocs」の使い方と仕組みを、初めて使う人にもわかるようにまとめたものです。
しばらく触っていなくて使い方や作りを忘れたときも、ここから読めば思い出せるようにしています。

内容は 2026-11-21 の時点のものです。OS を変えたら、このマニュアルも直します。

## ほかの文書との関係

- `docs/programming-guide.md`: Monocs の上でプログラムを書く人向けの詳しい手引き（使える関数、クセ、落とし穴）。第 6 章はその入口です。
- `docs/hardware-test.md`: 実機を最初に確かめたときの手順（LED での確かめ方など）。
- `docs/resume.md`: 開発を再開するときの短い手引き（よく使うコマンド、気をつけること、次の候補）。
- `CLAUDE.md`: 開発の経緯・測った数字・直した不具合のすべての記録。
- `docs/slimcc-codegen.md`・`docs/slimcc-compile-speed.md`: コンパイラ slimcc を良くする作業の手引き。

## 30 秒でわかる Monocs

```
$ ssh monocs                      # Pi 5 から Wi-Fi で入る（第 3 章）
/root> mi hello.c                 # エディタで C を書く
/root> run hello.c                # その場でコンパイルして動かす（第 6 章）
Hello, Monocs!
/root> gpio readall               # GPIO の様子（第 9 章）
/root> poweroff                   # 書き出して止める（第 5 章）
```
