# C の Web（中身が C のソースの WWW）の構想

2026-11-22 にユーザーと話した構想。**まだ作っていない**。土台はサンドボックス（`docs/sandbox.md`）。
ユーザーの考え: 今の Web がおかしくなったのは、検索から人を集めて広告でお金にする作りのせい。C の Web は、検索しにくく、
見つけ方はリンクと知り合いからの「これ面白いよ」（URL とハッシュをチャットで渡す）。標準のサンドボックスはネットワークを
許さないので、ページは見ている人のことを外に送れない（広告・トラッキングが作りの上で入りにくい）。

| 部品 | 中身 | サンドボックスの設計との関係 |
|---|---|---|
| ページ | 1 つの C のプログラム（フォルダでもよい）。画面（curses）に描き、キーとマウスで操作する | 標準の使える機能（画面・キー・マウス・時刻・乱数・計算） |
| 置き場所 | どの Monocs の `httpd` にも置ける（`/root/share` などの公開のフォルダ。そこだけパスワードなしで読める） | 今の `httpd` に公開のフォルダを足す |
| 取ってくる | `run URL#sha256=…` | 5.0 の HTTP ＋ハッシュ |
| リンク | ページが「次はこの URL へ」と頼むシステムコールを 1 つ足す。Monocs がそのページに移る。「戻る」も Monocs が覚える | 3.2 の使える機能に足す |
| ブラウザ | Monocs のコマンド（案: `cweb URL`）。取ってくる・確かめる・キャッシュする・動かす・履歴 | `run URL` の延長 |
| 見つけ方 | リンクと、知り合いからの URL とハッシュ。検索はわざと作らない | |

- **リンクにハッシュを入れる**: リンクを「URL ＋ハッシュ」で書けば、最初の 1 ページのハッシュを信頼するだけで、たどる先も全部、作った人が
  意図した中身だと確かめられる（ハッシュのつながりで信頼が伝わる。HTTP のままでもすり替えに強い）。リンク先が更新されるとハッシュが
  変わるので、「最新を見る」か「リンクを作ったときの版を見る」かを選べるようにする。
- 似たもの: Java のアプレット・Flash（守りの穴で消えた）、WebAssembly（いちばん近い考え方）、Gopher・Gemini（文字中心の Web）。

## 作る順（案）

1. サンドボックス（`docs/sandbox.md` の 8 の 1〜4: `cc --report`、EL0、システムコール、画面・キー・マウス）
2. `run URL`（HTTP ＋ハッシュ）と、`httpd` の公開のフォルダ
3. リンクのシステムコールとブラウザのコマンド（履歴・戻る）
4. 最初のページをいくつか作る（目次のページ、ゲーム、デモ）

**進み具合（2026-11-26）**: 作る順の 1〜3 は済み。
- 1: サンドボックス（cc --report、EL0、システムコール、中の C ライブラリ、curses、キャッシュ。docs/sandbox.md の 8）
- 2: `sandbox http://…#sha256=…`、httpd の公開のフォルダ /root/share
- 3: ブラウザ `cweb URL|FILE.c[#sha256=…]`（os/slimcc/cweb_cmd.c）と、リンクのシステムコール SYS_GO（7）。ページは `#include <cweb.h>`
  （/usr/lib/sandbox/cweb.h。サンドボックスのプログラムは -I /usr/lib/sandbox）の `cweb_go(URL)`（このページを終えて移る）・
  `cweb_back()`（戻る）。ブラウザは履歴を 32 まで覚え、戻る先がなければ終わる。リンクは今のページからの相対・/ から（同じサーバー、
  手元なら絶対パス）・http://…。.. は使えない。リンクの #sha256= は移った先で確かめる（最初のページのハッシュだけ渡せば、たどる先も
  確かめられる）。手元のファイルのページでも #sha256= を確かめる。ページに渡す argv[0] は今の URL（ハッシュを除く）。
  確かめ: QEMU（手元のファイル: 目次 → 2 ページ目（ハッシュ付きのリンク）→ 戻る → まちがったハッシュのリンクで止まる → q で終わる）、
  実機（Pi 5 のサーバーから a → b（相対）→ c（/ から）、ハッシュは a のだけ渡す）。
- 4: 最初のページ（samples/cweb/。SD カードの /usr/share/samples/cweb/）: index.c（目次。矢印キーと Enter）、snake.c（ヘビのゲーム）、life.c（ライフゲーム）、about.c（説明）。`cweb /usr/share/samples/cweb/index.c` で開く。目次からのリンクはハッシュなし（手元のサンプルなので。ページを直すたびに目次のハッシュを書き直さずに済む）。QEMU で、どのページも開いて戻れることを確かめた。
- 次の候補: https（人が公開したページ）、ページの中のほかのファイル（#include "x.h"）、If-None-Match、ブラウザの「戻る」をキーで（今はページが cweb_back を呼ぶ）。
